FIFA 19 Machine Learning Project
Project Overview

This project uses the FIFA 19 dataset to explore player data and build machine learning models.

The project covers the main steps of a machine learning workflow, starting with data preprocessing and feature engineering, followed by model training and evaluation.

Objectives
Explore and understand the FIFA 19 dataset.
Clean and preprocess the data.
Perform feature engineering.
Prepare the data for machine learning.
Train machine learning models.
Evaluate and compare model performance.
Extract useful insights from the results.
